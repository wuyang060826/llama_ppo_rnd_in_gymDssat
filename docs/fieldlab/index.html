How to read this comparison

Cards show arithmetic means. Differences use B minus A. Repeat numbers are archival labels and do not establish paired weather seeds. Checkpoint IDs refer to saved training episodes. The default pair illustrates a trade-off in this batch. Baseline comparisons, confidence intervals, and field validation require additional evidence.

EXPERIMENT DESIGN

From observation to action

  1. Observe

    Gym-DSSAT simulates crop growth and supplies numerical field observations.

  2. Encode

    LLaMA encodes observations serialized as text for the PPO actor–critic.

  3. Act

    The policy selects irrigation and nitrogen levels. RND adds an exploration reward during training.

FROM DEMO TO EXPERIMENT

Reproduce the evidence

Explore the archive in your browser, regenerate the summary with Python, then follow the training guide to run your own experiment.

git clone https://github.com/wuyang060826/llama_ppo_rnd_in_gymDssat.git
cd llama_ppo_rnd_in_gymDssat
python scripts/demo_results.py

The archive summary uses Python 3.9+ with the standard library. Training additionally requires CUDA, DSSAT-PDI, and compatible model weights.
